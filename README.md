# 🎶 Waves of the Harmony

## A simple 2D platform game made for the game jam Game Off 2025

- In this game, you have to defeat the monsters and bring back the magic and music for the world!
- To do this, you have some musical instruments, able to destroy the monsters with their notes

- Stage by stage, you recover one more instrument, and bring more colour to the world
